🟣 4. Workflow des Statuts

Bulletin — Machine à états

BROUILLON ──► VÉRIFIÉ ──► VALIDÉ ──► PUBLIÉ
    ▲                                              │
    └──────────── RÉVOQUÉ ◄──────────────┘
ActionRouteTransition
VérifierPOST .../verify-statusBrouillon → Vérifié
ValiderPOST .../validateVérifié → Validé (enregistre validateur + date)
PublierPOST .../publishValidé → Publié (PDF + HMAC + code + email + SMS auto)
RévoquerPOST .../revokeRaison obligatoire, seulement si publié

Certification — Workflow

ACTIVE ──► REVOKED (révocation manuelle)   |   ACTIVE ──► EXPIRED (automatique si validUntil dépassé)

Le statut est automatique — retiré des formulaires, change uniquement via boutons workflow.

🟣 7. Sécurité HMAC-SHA256

MéthodeDétails
signBulletin()HMAC-SHA256 sur : studentId + name + year + semester + average + lignes sérialisées
signCertification()HMAC-SHA256 sur : studentId + type + uniqueNumber + verificationCode + issuedAt
verifyBulletin()Comparaison timing-safe avec hash_equals()
verifyCertification()Idem — empêche les attaques par timing

Objectif : Garantir que les documents n'ont pas été falsifiés après émission.

🟣 8. Vérification Publique

Route : GET /verify/{code} — accessible sans authentification

  • Recherche bulletin OU certification par verificationCode
  • Affiche : type, nom masqué (vie privée: Ra*** G***), année, statut
  • Vérifie l'intégrité HMAC en temps réel
  • Affiche raison de révocation si applicable

🎬 PARTIE 2 — Scénario de Démonstration

Durée estimée : 15-20 minutes  |  Prérequis : Serveur Symfony lancé, base de données avec données

📌 PHASE 1 — Connexion & Dashboard 1 min
1 Ouvrir http://127.0.0.1:8000/
2 Se connecter en tant qu'admin
3 Montrer le dashboard admin — vue d'ensemble
📌 PHASE 2 — CRUD Bulletins 3 min
4 Bulletins → Nouveau Bulletin
5 Sélectionner étudiant, année, semestre
6 Ajouter des lignes de notes (modules avec CC, DS, Exam)
7 Montrer : calcul automatique moyenne (CC 10% + DS 20% + Exam 70%)
8 Montrer : mention attribuée automatiquement
9 Montrer : statut = Brouillon — pas modifiable manuellement
10 Sauvegarder → bulletin créé

11 Retour liste → taper dans la recherche → filtrage dynamique en temps réel
12 Montrer le compteur qui se met à jour
13 Cliquer sur les en-têtes de colonnes pour trier
14 Modifier un bulletin → changer une note → Sauvegarder
📌 PHASE 3 — Workflow des Statuts 2 min
15 Ouvrir un bulletin Brouillon
16 Cliquer Vérifier → statut Vérifié ✅
17 Cliquer Valider → statut Validé ✅
18 Cliquer Publier → statut Publié ✅
19 Montrer : PDF généré + HMAC signé + code vérif + email envoyé automatiquement
20 Montrer le bouton Révoquer → saisir raison → bulletin révoqué
Le statut suit un workflow strict : Brouillon → Vérifié → Validé → Publié. Pas de changement manuel. Chaque transition est tracée dans l'audit log.
📌 PHASE 4 — PDF & QR Code 1 min
21 Sur un bulletin publié → Télécharger PDF
22 Montrer : design EduSmart, notes, logo, signature, cachet
23 Montrer le QR Code intégré dans le PDF
24 Scanner le QR → ouvre la page de vérification publique
📌 PHASE 5 — Vérification Publique & HMAC 1 min
25 Aller sur /verify/{code} (via QR ou en tapant le code)
26 Montrer : type, nom masqué (vie privée), statut
27 Montrer : "Intégrité vérifiée ✅" = vérification HMAC-SHA256
Si quelqu'un modifie le document dans la base, le HMAC ne correspondra plus et ça affichera "Document falsifié".
📌 PHASE 6 — Email & SMS 1 min
28 Sur un bulletin publié → cliquer Envoyer Email 📧
29 Montrer la boîte de réception (email HTML premium + PDF joint)
30 Cliquer Envoyer SMS 📱 (si Twilio configuré)
L'email et le SMS sont aussi envoyés automatiquement lors de la publication. Le SMS formate le numéro français en +33.
📌 PHASE 7 — CRUD Certifications 2 min
31 Certifications → Nouvelle Certification
32 Sélectionner étudiant → montrer les semestres chargés dynamiquement (API interne)
33 Choisir type REUSSITE → Sauvegarder
34 Montrer : numéro unique EDU-2026-RE-000001, code vérif, HMAC
35 Recherche dynamique sur la liste + tri par colonnes
36 Générer PDF → télécharger → montrer QR code
37 Envoyer Email + Envoyer SMS
38 Révoquer → saisir raison → vérifier sur /verify/{code} → "Révoqué"
📌 PHASE 8 — Intelligence Artificielle ⭐ 4 min
39 Aller dans Analyse AI (/admin/ai/)
40 Montrer le badge "Groq AI Connecté" ✅

Analyse individuelle :
41 Sélectionner un étudiant → Analyser → score/100, forces, faiblesses
42 Recommandations → conseils personnalisés, objectifs SMART

Tendances de classe :
43 Année + semestre → Analyser la Classe → moyenne, écart-type, distribution

Prédiction de réussite :
44 Cliquer Prédiction de Réussite 🎯 → probabilité %, risque, tendance pour chaque étudiant
L'IA analyse les données réelles de la base pour prédire quels étudiants risquent l'échec.

Détection d'anomalies :
45 Cliquer Détecter Anomalies 🔍 → écarts suspects, chutes brutales, incohérences
Ça permet de détecter les erreurs de saisie ou les fraudes potentielles.

Certifications AI :
46 Cliquer Bilan Global 📋 → stats, couverture, alertes, recommandations
47 Cliquer Suggestions ✨ → certifications éligibles par étudiant avec priorité
L'IA compare les données de chaque étudiant avec les 6 types de certifications et recommande celles qui manquent.

Chatbot AI :
48 Taper : "Quel étudiant a la meilleure moyenne ?" → réponse avec vrais noms/notes
49 Taper : "Combien de certifications ont été émises ?" → données réelles
50 Taper : "Quelle est la capitale de la France ?" → refusé (restreint éducation)
Le chatbot a accès à toute la base de données en temps réel mais est strictement restreint aux questions éducatives.
📌 PHASE 9 — API REST 2 min
51 Ouvrir navigateur et montrer :
GET /api/v1/bulletins → liste JSON avec pagination
GET /api/v1/bulletins/verify/{code} → vérification via API
GET /api/v1/certifications/types → types disponibles
GET /api/v1/certifications/student/{id}/stats → statistiques
GET /api/v1/sms/health → santé du service SMS
GET /api/v1/ai/health → santé IA + liste features
Toutes les fonctionnalités sont aussi accessibles via API REST pour intégration avec d'autres systèmes. 28 endpoints au total.
📌 PHASE 10 — Audit Log & Espace Étudiant 1 min
52 Audit Log → montrer toutes les actions tracées
Chaque action sur un bulletin ou certification est enregistrée avec l'utilisateur et la date.
53 Se déconnecter → se reconnecter en étudiant
54 Montrer : Mes Bulletins, Mes Certifications
55 Mon Analyse AI → lancer analyse + chatbot étudiant
📌 PHASE 11 — Dark Mode (Bonus) 15 sec
56 Cliquer le toggle dark mode 🌙 → tout est lisible
Le thème est sauvegardé en localStorage.
